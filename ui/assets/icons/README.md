# Iconos de la interfaz

- Iconos originales del proyecto, de 24×24 px, con trazo de 2 px y color negro (`#000000`).
- El trazo negro está pensado para recolorearse en Slint con `Image { colorize: <color>; }`.
- Convención de nombres: kebab-case en minúsculas (por ejemplo `chart-bar.svg`, `alert-triangle.svg`).
- Los iconos son de una sola tinta: no usan texto, degradados, estilos CSS ni referencias externas.
